# Cvičení — Programování a programovací jazyky

## Cvičení 1 — Klasifikace jazyků (★☆☆)

Do tabulky zařaďte tyto jazyky:

`Python`, `C++`, `HTML`, `Java`, `Assembler`, `Ruby`, `XML`

Sloupce: *programovací / značkovací*, *kompilovaný / interpretovaný / VM*.

@reseni
| Jazyk | Typ | Spuštění |
|-------|-----|----------|
| Python | programovací | interpretovaný |
| C++ | programovací | kompilovaný |
| HTML | značkovací | — |
| Java | programovací | VM (bytecode) |
| Assembler | programovací | kompilovaný |
| Ruby | programovací | interpretovaný |

@end

---

## Cvičení 2 — Výhody a nevýhody (★★☆)

Vyberte si jeden kompilovaný a jeden interpretovaný jazyk. Napište 3 situace, kdy byste zvolili každý z nich.

@reseni
**C++ (kompilovaný):** hry s vysokým výkonem, embedded systémy s málo RAM, knihovny kde záleží na rychlosti.

**Python (interpretovaný):** učení programování, rychlý prototyp skriptu, analýza dat a automatizace.
@end

---

## Cvičení 3 — Diskuze (★☆☆)

Proč je pro výuku v 1. ročníku vhodný Python spíše než C++? Uveďte alespoň 3 argumenty.

@reseni
- Jednodušší syntaxe (odsazování, méně symbolů).
- Rychlejší zpětná vazba — program běží bez kompilace.
- Méně „technické“ povinnosti (paměť, typy) na začátku.
- Chyby jsou srozumitelnější pro začátečníka.
@end
